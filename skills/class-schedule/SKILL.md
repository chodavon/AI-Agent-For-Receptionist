# Class schedule

## Quick answers
- Course durations range from **1 day to 40 hours** (about 5 days).
- Specific class times (morning/afternoon/evening) are **not published** on the website.
- Delivery mode (in-person, online, or hybrid) is **not published** on the website.
- Contact admin@aicacademy.ai or +855 85 518 925 for exact class times.

## How to answer
- Duration per course is in `timetable.yaml`. Read it before answering.
- For start dates, use the academic-calendar skill.
- If asked about specific session times, say they are not published yet and offer to take a message.

## When to hand off
- Specific class times, room assignments, or schedule changes: take a message for admin@aicacademy.ai.
